Released on **2026-08-19**.

### Fixed
- `vertex test` reported `no Vertex project found` when a project's
  `vertex.jsonc` could not be parsed. An unreadable config falls back to the
  default source directory, which a project that configured another name does
  not have, and the missing directory shadowed the reason it was missing. The
  parse error is now reported instead.
